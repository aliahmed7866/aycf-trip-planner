Automatic morning scan

  1. Refresh the newest AYCF PDF data after publication.
  2. Detect whether the PDF publication timestamp changed.
  3. Check every advertised route for each of the next four days.
  4. Persist both positive and zero-flight checks so searches do not repeat work.

Fallback behavior

If the morning cache is incomplete, the app can optionally fall back to your live authenticated Wizz session. Set AYCF_ALLOW_LIVE_FALLBACK=false if you want database-only behavior.
